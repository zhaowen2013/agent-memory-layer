- 默认零依赖(HashingEmbedder + SQLiteVectorStore + ExtractiveSummarizer),离线可跑
- 三层接口均可替换:embedder / vector store / summarizer
- 提供 CLI (`agent-memory`) 和 Python SDK (`MemoryLayer`)

## 关键文件
- `agent_memory/core.py` — MemoryEntry 数据结构
- `agent_memory/embeddings.py` — 三个 EmbeddingProvider 实现
- `agent_memory/stores.py` — SQLiteVectorStore + ChromaStore
- `agent_memory/summary.py` — ExtractiveSummarizer + LLMSummarizer

- `agent_memory/cli.py` — argparse CLI
- `examples/basic.py` — 演示
- `tests/test_core.py` — pytest 冒烟测试

## 技术选型理由
- 默认哈希向量 + SQLite 保证零依赖,降低上手门槛(开源项目核心是"有人愿意试用")
- 可插拔架构确保进阶用户也能用 semantic embedding + ANN
- README 用英文,便于 GitHub 国际曝光
